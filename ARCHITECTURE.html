A complete private villa rental CRM with AI call analysis, WhatsApp inbox, and revenue intelligence — built for luxury hospitality operators.

30 API Endpoints

What is HAIP Villa?
One platform for the
entire guest journey

Think of it as a CRM + Call Centre Analytics + WhatsApp Inbox + Revenue Dashboard — all in one. Built specifically for private villa rental businesses.

🏖️
Guest Management (CRM)

Store every guest's profile — contact details, nationality, language, past stays, preferences, GDPR consent, and VIP tags. A full 360° view of each guest in one click.

📋
Inquiry Pipeline (Kanban)

Track every enquiry from the first WhatsApp message to confirmed booking. Move cards through stages: New → Contacted → Quoted → Negotiating → Confirmed. See revenue potential at every stage.

🏡
Villa & Booking Management

Manage your property catalogue, nightly rates, seasonal pricing, and confirmed bookings. Each booking gets a unique reference (e.g. VR-2026-84721) and tracks payment status.

🤖
AI Call Quality Analysis

Upload a call recording. The AI automatically transcribes it (using Whisper — running locally on your computer), analyses the agent's performance, scores it out of 10, detects guest emotions, and gives coaching recommendations.

💬
WhatsApp Inbox

All guest WhatsApp messages appear in one unified inbox. The platform receives messages via Meta's official Cloud API (webhook), auto-creates guest profiles if new, and lets your team reply from the dashboard.

📣
Campaigns

Broadcast WhatsApp or email campaigns to your guest list — seasonal offers, availability notifications, post-stay feedback requests. Schedule or send immediately.

Why separate layers? Each layer can be scaled, replaced, or debugged independently. The browser doesn't know how the database is structured. The database doesn't know what the UI looks like. The backend is the only layer that knows everything — and it controls what data each user is allowed to see.

AI Intelligence
How a 90-second call becomes a QA report

The call analysis pipeline runs entirely on your machine (except Gemini). Here's every step — from audio file to actionable insights.

📁
1. Upload
You drag an MP3/WAV/M4A/FLAC file (max 200MB) into the browser. It's sent via HTTP multipart form to the backend's /analyze/audio endpoint.
🔄
2. Pre-processing
ffmpeg converts the audio to a standard WAV format that Whisper can process. Handles any input codec — MP3, AAC, OGG, WebM.
ffmpeg · local
🎙️
3. Transcription (STT)
faster-whisper runs the Whisper "base" model locally. No internet needed. Produces time-stamped word segments and detects the language automatically.
faster-whisper · CPU/GPU · local
🧠
4. Emotion Detection (optional)
SpeechBrain + wav2vec2 model analyses the audio waveform (not words — the tone) to detect emotions: happy, frustrated, angry, neutral. Produces a timeline of emotional states per 5-second window.
SpeechBrain · local · optional
✨
5. AI QA Analysis
The full transcript is sent to Gemini 2.5 Flash (Google's API) with a detailed prompt asking it to: score the call out of 10, summarise what happened, identify key issues (missed upsell, wrong info given), and produce coaching recommendations. Requires a free Gemini API key.
Gemini 2.5 Flash · cloud API
💾
6. Save & Display
All results are saved to PostgreSQL in the calls and call_analysis tables. Browser is redirected to the call detail page showing transcript, score, emotions, and recommendations.
PostgreSQL · saved permanently
🔌
No Gemini key? The platform degrades gracefully. Whisper still transcribes the audio. The call is saved with the transcript. But QA score, summary, and recommendations won't appear. Add a key in Settings to unlock AI features instantly — no restart needed.
🔒
Privacy: Audio files are stored locally in backend/audio_files/. Transcription runs on your machine. Only the text transcript is sent to Gemini for analysis — no audio goes to the cloud.
📊
What Gemini returns
●
QA Score — 0.0 to 10.0. Based on agent professionalism, information accuracy, empathy, closing technique.
●
Sentiment — Overall call mood: positive, negative, or neutral.
●
Summary — 2–3 sentence plain-English description of what happened in the call.
●
Key Issues — List of things that went wrong: missed upsell, wrong pricing quoted, rushed goodbye.
●
Recommendations — Actionable coaching tips: "Always confirm check-in time before ending call".

Security
How login and permissions work

The platform uses JWT (JSON Web Tokens) for stateless authentication and role-based access control (RBAC) so different team members see different things.

Login Flow

1
You type email + password
Browser sends POST /auth/login with credentials as JSON.
2
Backend verifies
Looks up the user in PostgreSQL. Compares password against bcrypt hash. If wrong → 401 error.
3
JWT token issued
If correct, backend returns a signed token containing your user ID and role. Expires after 8 hours.
4
Token stored
Browser saves token in localStorage. Every subsequent API call sends it as Authorization: Bearer {token}.
5
Backend validates each request
FastAPI middleware decodes the token on every request. If expired or tampered → 401. If valid → request proceeds.

Roles & Permissions

Role View Dashboard Manage Guests Manage Villas Change Settings / Keys Manage Users
owner ✓ ✓ ✓ ✓ ✓
manager ✓ ✓ ✓ ✓ —
concierge ✓ ✓ — — —
reservations ✓ — — — —
readonly ✓ — — — —
🛡️
How role enforcement works in code: Each FastAPI endpoint uses a Depends(require_roles("owner","manager")) guard. If your token's role isn't in the allowed list, you get a 403 Forbidden response — even if you know the URL. The check happens server-side, not just in the browser.
Deployment
How to run the platform locally

Everything runs on your Windows machine. No cloud hosting required.

⚡
Backend (FastAPI)

Runs on port 8001. Needs PostgreSQL running first.

# Navigate to backend folder
cd C:\HAIP-Villa\backend
# Start the server
python -m uvicorn main:app
--host 0.0.0.0 --port 8001

API docs available at localhost:8001/api/docs

⚛️
Frontend (Next.js)

Runs on port 3001. Needs the backend running first.

# Navigate to frontend folder
cd C:\HAIP-Villa\frontend
# Start the dev server
npm run dev

Open localhost:3001 in your browser

Default login credentials: Email: owner@haip.local · Password: haip1234 · Role: owner (full access). These are pre-seeded into the database by running python seed.py in the backend folder.
